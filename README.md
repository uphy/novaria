# novaria

降ってくる隕石を打ち上げて、惑星を守るアクションパズル。スマホのブラウザでそのまま遊べる。

**▶ https://novaria.uphy.dev**

同じ柄の隕石を 3 つ揃えると点火し、上に積もった隕石ごと宇宙へ打ち上がる。
消すのではなく打ち上げるので、揃える場所しだいで大きな塊がまとめて飛んでいく。
積もった隕石が大気圏に届くと、その惑星は滅亡する。

## 遊び方

- 隕石を指で掴み、その列の中で上下に動かす
- 同じ柄が縦か横に 3 つ並ぶと点火し、上に乗った隕石ごと打ち上がる
- 打ち上がった塊はしばらく空中に留まる。そのあいだに塊の中で揃え直すと、もう一度点火してさらに高く上がる
- 浮いている塊に、下から別の塊をぶつけると合体する
- 列の一番上を上へ払うとシュート。飛んでいる塊を押し上げ、降ってくる同じ柄の隕石とも相殺する
- 点火した隕石は燃えカスになる。燃えカスは揃えられないが、しばらくすると元の隕石に戻る
- ときどき降ってくるレアメタルは、宇宙へ出すと 10,000 点
- あと 1 段で大気圏に届く列は橙に、届いた列は赤く光る。赤いうちに崩せないと滅亡

PC では上下キーと Enter でメニューを選び、Esc か P で一時停止できる。
一時停止の「ヒント」をつけると、次に動かすとよい隕石と運び先が矢印で出る。攻めの手は緑、崩さないと危ない列を守る手は橙と赤で、あと何秒もつかも出る。ヒント中は一時停止の「速さ」でゲームをゆっくりにできる（一人用と惑星めぐりだけ。ゲームごとにつけ直す。つけたゲームは記録にもランキングにも残らない）。

## モード

| モード | 中身 |
|---|---|
| 一人用 | 積みきるまで続く。得点はランキングに載る |
| 惑星めぐり | 6 つの惑星を順に渡る。惑星ごとに重力・降る量・柄の数・空の色が違い、決まった数を打ち上げると次へ進む |
| 対戦（CPU） | 強さを 3 段階から選ぶ。打ち上げた隕石が相手の惑星に燃えカスとして降る |
| 対戦（オンライン） | 待っている人か、同じ合言葉を入れた人とつながる |

## スマホに入れる

Android の Chrome は「ホーム画面に追加」でインストールできる。iPhone は Safari の共有メニューの「ホーム画面に追加」で全画面になる。
一度開けば、ランキングとオンライン対戦以外はオフラインでも遊べる。

## 扱う情報

広告・アクセス解析・Cookie は使っていない。
端末には無作為の id・名前・自己ベスト・戦績を残す。ランキングに送るのは、名前を決めた人の 1 人用の結果（名前・得点など）だけで、
id は誰にも見せない。ゲーム内の「記録」→「名前と公開」→「ランキングから消す」で、自分の行をいつでも消せる。
詳しくはゲーム内の「記録」→「名前と公開」→「扱う情報」にある。

## 手元で動かす

Node.js 22 と pnpm 10 で動く。

```sh
pnpm install
pnpm dev       # http://localhost:5173
pnpm dev:api   # ランキングとオンライン対戦ごと動かす（http://localhost:8788）
pnpm test
```

TypeScript と Canvas で書いていて、フレームワークは使っていない。配信は Cloudflare Workers（ランキングは D1、オンライン対戦は Durable Object）。
コマンドの一覧・中の作り・変更の進め方・自分の Cloudflare への置き方は [docs/development.md](docs/development.md)、
ルールの細かい決めごとは [docs/decisions.md](docs/decisions.md) にある。

## 原作について

既存のパズルゲームのルールを下敷きにした、個人の非公式な作品で、原作の権利者とは関係がない。
名前・惑星・絵柄・音はすべて独自のものにしてある。

## Issue と PR

不具合の報告や提案は Issue へ。脆弱性は公開せず、[SECURITY.md](SECURITY.md) の手順で知らせてほしい。
PR を送るときは [docs/development.md](docs/development.md) を一読し、`pnpm typecheck`・`pnpm test`・`pnpm check:names` を通しておく。
